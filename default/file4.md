# Playbook For KLO Monitoring

## DataOS Cumulus Sources and Pipelines

In DataOS Cumulus there are in total 4 INK and 10 LASER sources for which we run 5 Pipelines in total daily in production.

### Pipelines that run daily for each sources:

- RAW
- STDRAW
- REDSHIFT
- DELTALAKE
- OCV

The sequence in which this pipelines should run is in the same sequence as listed above. OCV Pipeline runs only for laser sources excluding HPPK_AMPV.

## How to Trigger

### Triggering manually from Databricks:

First RAW Job will be triggered in Databricks that will do the initial processing of raw data from Pepto path and store the output as delta lakes in s3 location. This output from RAW will be taken as a input for STDRAW Job that will do the main processing and standardize the data and store it in parquet format in s3 bonded storage locations. This output from STDRAW is then taken as input for REDSHIFT, DELTALAKE & OCV Jobs that perform further processing and store the final result into Redshift & Delta lake locations respectively. REDSHIFT, DELTALAKE & OCV Jobs can be triggered in parallel for a particular source.

Proper parameters has to be given when triggering a job manually in Databricks. In case of enabling the DAGs in Airflow parameters is passed automatically in between the pipelines.

In case of OCV only one job should run at a time for a single source. Once the job is finished than we can trigger OCV Job for another source in case of manual triggering of Jobs. We should not trigger OCV for multiple sources simultaneously as it can result in Job failure.

For a particular source for a particular pipeline only one job should be running at a time. For example for PEINK RAW Job only one run should be going on at a time. If we trigger two runs for PEINK RAW Job simultaneously it could result in job failure.

### Enable DAGs in Airflow:

We can enable DAGs in Airflow to run the whole pipeline cycle for previous days data. Remember that whenever we enable a DAG or trigger a DAG it runs Databricks Jobs for previous date only. To trigger DAG to run the jobs for a particular DateToProcess we have to give this as key and value in configurations when we select trigger DAG with config option. The exact JSON value to be given when triggering DAG with config is specified in below tables.

### INK Sources:

- PEINK
- GOTHAM_LEDM
- WPPGEN2_SCHEDULED
- WPPGEN1

### LASER Sources:

- JAM_LEDM
- JAM_MHIT
- PRINTERNET_MHIT
- PELASER_PRINTERNET
- PELASER_DPP
- GOTHAM_LEDM
- WJA_LEDM
- WJA_MHIT
- WPPGEN2_SCHEDULED
- HPPK_AMPV

GOTHAM_LEDM & WPPGEN2_SCHEDULED are two sources that are common in both INK & LASER.

In Total there are 13 Jobs in RAW, 14 Jobs in STDRAW, 14 Jobs in REDSHIFT, 14 Jobs in DELTALAKE & 9 Jobs in OCV that run daily. In total 64 Jobs run daily for cumulus classic sources.
